# Coca-Cola Q1 FY26 Icon Crop Validation

Dataset: `coca-cola-q1-fy26`

Source: `input/processed/coca-cola-q1-fy26.png`

Validation command:

```sh
python3 scripts/extract_icon_crops.py --spec input/icon-crop-specs/coca-cola-q1-fy26.json
```

## Accepted Crops

- `company-wordmark.png`: the black Coca-Cola script wordmark shown above the
  revenue flow. A black foreground filter plus edge-connected background removal
  leave the script only; the blue title above (y ≤ 219) and the chart flows below
  are outside the crop box, so no title, source values, or connector fragments
  are captured.
- `globe-emea.png` / `globe-latam.png` / `globe-ucan.png` / `globe-apac.png`: the
  four region-marker globe icons to the left of the EMEA / LATAM / UCAN / APAC
  segment names (Europe-Africa, Americas, North-America, and Asia-Pacific views).
  Edge-connected background removal clears the light `#f2f2f2` corners while the
  light interior oceans are enclosed by the sphere rim and continents, so they are
  not edge-connected and are correctly retained. Each crop box ends at x ≤ 300,
  left of the segment label text, so no name glyphs are captured.

All accepted crops are complete, visually centered, and free of unrelated labels,
chart marks, connector fragments, watermarks, neighboring-icon parts, and
publisher/creator branding in the extracted crop panel of the validation sheets.
`crop-report.json` reports `validation.edgeForegroundPixels: 0`,
`validation.forbiddenForegroundPixels: 0`, and a `validation.centerOffset` within
the configured `maxCenterOffset` for every crop. The wordmark crop box spans the
full script height y247–447 so the top swash flourishes of the two Cs are not
clipped (a too-shallow box starting at y276 clipped ~19px off the top).

## Runtime Use

Image embedding mode is used: the Coca-Cola script wordmark is not worth hand
vector reconstruction, and the four globes are photo-style raster markers. Runtime
copies were generated by the crop spec under:

`data/assets/raster-annotations/coca-cola/`

The d3 dataset explicitly opts in with `render.allowRasterAnnotations = true` and
references only the runtime copies, not `data/assets/icon-references/`.

## Skipped Source Marks

- Bottom-left "HOW THEY MAKE MONEY" publisher mark and mini Sankey logo.
- Bottom-center `appeconomyinsights.com`.
- Bottom-right App Economy Insights badge and wordmark.

These are publisher/creator attribution elements, not Coca-Cola company or
business-segment semantics. The "Bottling investments" and "Other" segments have
no independent brand icon and are intentionally left icon-less.
