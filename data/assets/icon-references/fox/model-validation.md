# FOX Q3 FY26 Icon Crop Validation

Dataset: `fox-q3-fy26`

Source: `input/processed/fox-q3-fy26.png`

Validation command:

```sh
python3 scripts/extract_icon_crops.py --spec input/icon-crop-specs/fox-q3-fy26.json
```

## Accepted Crops

- `company-wordmark.png`: the blue FOX wordmark shown above the revenue flow. Blue foreground filter plus edge-connected background removal leave the wordmark only; no title, source values, or chart links.
- `cable-network-cluster.png`: Cable Network Programming brand cluster — Fox News Channel, Fox Business, FS1, FS2. The segment label text ("Cable Network Programming") is x-interleaved with the logos (label starts at x≈184 on the top rows while FS1/FS2 reach x≈225), so the two label-text fragments are blanked with `excludeBoxes` (5,288 px). The extracted panel shows the three logos only.
- `television-cluster.png`: Television brand cluster — Fox, Fox TV Stations, MyNetworkTV, Tubi. The "Television" label and margin text sit at x≥276, well outside the crop, so no exclusion was needed.

All accepted crops are complete, visually centered, and free of unrelated labels, chart marks, connector fragments, watermarks, neighboring-icon parts, and publisher/creator branding in the extracted crop panel of the validation sheets. `crop-report.json` reports `passes: true`, `edgeForegroundPixels: 0`, and `forbiddenForegroundPixels: 0` for every crop.

## Runtime Use

Image embedding mode is used because the segment clusters contain multiple brand-specific bitmap marks that are not worth per-mark vector reconstruction. Runtime copies were generated by the crop spec under:

`data/assets/raster-annotations/fox/`

The d3 dataset explicitly opts in with `render.allowRasterAnnotations = true` and references only the runtime copies, not `data/assets/icon-references/`.

## Skipped Source Marks

- Bottom-left "HOW THEY MAKE MONEY" publisher mark and mini Sankey logo.
- Bottom-center `appeconomyinsights.com`.
- Bottom-right App Economy Insights badge and wordmark.

These are publisher/creator attribution elements, not FOX company or business-segment semantics. The "Corporate & Other" segment has no independent brand icon and is intentionally left icon-less.
